# AdminFeedback
![AdminFeedback Dashboard](./Снимок%20экрана%202026-09-24%20141507.png)
Внутренняя аналитическая панель для кофейни «Штиль» в Актау.

Дашборд собирает обратную связь гостей и показатели команды, превращая данные из Google Sheets в единый интерфейс для оценки качества сервиса, отзывов сотрудников и динамики показателей.

## Возможности

* просмотр среднего рейтинга команды;
* количество полученных отзывов;
* анализ негативных отзывов — 3 звезды и ниже;
* рейтинг сотрудников;
* определение сотрудника с лучшим результатом;
* статистика отзывов по сотрудникам;
* анализ QR-сканов;
* расчёт конверсии сканов в отзывы;
* статистика переходов с платформ:

  * 2GIS;
  * Яндекс;
  * Instagram;
* фильтрация по периоду;
* выбор конкретного сотрудника;
* режим просмотра негативных отзывов;
* анализ динамики рейтинга команды;
* адаптивный интерфейс для desktop и mobile.

## Как это работает

Данные хранятся в Google Sheets и используются как источник аналитики.


Google Sheets
     │
     ├── Отзывы
     │
     ├── QR-сканы
     │
     └── Переходы с платформ
             │
             ▼
        Google GViz API
             │
             ▼
        JavaScript
             │
             ├── Парсинг данных
             ├── Фильтрация
             ├── Расчёт статистики
             ├── Анализ рейтингов
             └── Формирование интерфейса
                     │
                     ▼
              AdminFeedback


Приложение работает полностью на стороне браузера. Отдельный backend или база данных для самого дашборда не требуются.

## Основные метрики

### Средний рейтинг

Рассчитывается на основе всех валидных отзывов за выбранный период.

### Негативные отзывы

К негативным относятся оценки:


1–3 звезды


Такие отзывы выделяются в интерфейсе и могут использоваться для быстрого поиска проблемных ситуаций.

### Рейтинг сотрудников

Для каждого сотрудника отображаются:

* количество отзывов;
* средняя оценка;
* количество связанных QR-сканов;
* активность на внешних платформах.

### Лучший сотрудник

Лидер определяется на основе среднего рейтинга отзывов за выбранный период.

### Конверсия QR

Дашборд сопоставляет количество QR-сканов с количеством отзывов:


конверсия = отзывы / QR-сканы × 100%


Это позволяет оценивать, насколько эффективно QR-механика приводит гостей к оставлению обратной связи.

## Периоды

Данные можно просматривать:

* за всё время;
* за отдельный месяц.

При выборе периода статистика и показатели команды пересчитываются автоматически.

## Источник данных

Проект использует Google Sheets как источник данных через Google Visualization API (GViz).

Используются отдельные листы/диапазоны для:

* отзывов;
* QR-сканов;
* переходов с внешних платформ.

JavaScript получает данные в формате GViz, преобразует их в структуры приложения и затем рассчитывает показатели.

## Запуск

Поскольку приложение состоит из статических файлов, для запуска достаточно открыть:


index.html


Для локальной разработки можно использовать любой простой HTTP-сервер.

Например, через Python:


python -m http.server 8000


После этого открыть:


http://localhost:8000


## Google Sheets

В `app.js` указывается идентификатор Google Sheets:


const sheetId = 'YOUR_SHEET_ID';


На его основе формируются GViz endpoints для получения данных.

Приложение использует несколько источников:


REVIEWS_URL
SCANS_URL
PLATFORM_CLICKS_URL


Для корректной загрузки данных таблица должна быть доступна приложению через используемый способ чтения Google Sheets.

## Обработка ошибок

Если основной источник отзывов временно недоступен, приложение использует небольшой набор fallback-данных, чтобы интерфейс не оставался полностью пустым.

Для QR-сканов и статистики платформ при ошибке загрузки используются пустые наборы данных.

Ошибки загрузки выводятся в консоль браузера.

## Адаптивность

Интерфейс рассчитан как на desktop, так и на мобильные устройства.

На небольших экранах:

* sidebar скрывается;
* появляется компактный mobile header;
* карточки переходят в одну колонку;
* фильтры адаптируются под ширину экрана;
* отзывы перестраиваются в вертикальный формат.

## Назначение

AdminFeedback предназначен для внутреннего использования командой кофейни «Штиль».

Главная задача проекта — сделать обратную связь гостей измеримой и удобной для ежедневного анализа:


Отзывы
  ↓
Рейтинг
  ↓
Сотрудники
  ↓
Проблемные отзывы
  ↓
Аналитика сервиса


## Ограничения

Проект является клиентским аналитическим интерфейсом и не содержит собственного backend.

Поэтому:

* данные зависят от доступности Google Sheets;
* структура Google Sheets должна соответствовать ожидаемому формату;
* вычисления выполняются в браузере;
* доступ к данным контролируется настройками самого источника Google Sheets.
