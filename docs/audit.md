# Проверка AdminFeedback

Дата: 16 октября 2026. Исходная версия: `af7bc0c`.

## Исправления

| Область | До | После |
| --- | --- | --- |
| Внешний текст | Имена и комментарии вставлялись через `innerHTML` | Создание DOM с `textContent`; XSS проверяется в браузере |
| Отказ источника | Подставлялись выдуманные отзывы, а UI сообщал об успешном обновлении | Явные состояния каждого источника; недоступные метрики `—`; демо только по явному URL |
| Даты | Невалидная или пустая дата становилась текущей; 31 февраля нормализовалось в март | Строгая проверка; ошибочные строки пропускаются с количеством в баннере |
| Оценки | Произвольные числа ограничивались до 5 | Только допустимые значения/форматы от 1 до 5 |
| Фильтры | Метрики, сканы и переходы использовали разные scopes | Период и сотрудник согласованы для всех показателей |
| Прототипы | Агрегация имён в обычном объекте | `Map`, безопасный и для имени `__proto__` |
| Метрики недели | За «последнюю неделю» принималась неделя вокруг самого свежего отзыва | Календарные окна в зоне Актау, исторический месяц завершается на границе месяца |
| HTML | Два одинаковых ID; JS ссылался на отсутствующие блоки | Уникальные ID и согласованная разметка |
| Производительность | Повторные проходы по сканам/переходам для каждого сотрудника; вся лента сразу в DOM | Однопроходная агрегация, параллельные источники, 30 отзывов за страницу |
| Сеть | Неограниченное ожидание и сторонний proxy fallback | Timeout/abort; прямые запросы к Google без сторонних relay |
| Дизайн | Статическая панель, очень мелкая типографика, неработающие элементы | Морская визуальная система, SVG-волны, график, анимированные числа, hover/reveal, mobile-nav, поиск |
| Доступность | Нет паузы анимации, focus и согласованных ARIA-состояний | Пауза с сохранением предпочтения, reduced motion, keyboard focus, skip-link, aria-pressed, aria-live |
| Разработка | Нет тестов и CI | Node tests, Playwright, axe и GitHub Actions |

## Проверки

- 20 unit-тестов: парсинг GViz, дат, оценок, таймаут, параллельность, partial/stale errors, метрики, фильтры, календарные окна.
- 13 браузерных сценариев Chromium: фильтры, XSS, отказы/пустые данные, stale refresh, пагинация, явное демо без сетевых запросов к Sheets, переключение и сохранение анимации, reduced motion.
- Адаптивность: 320, 390, 768 и 1440 px; горизонтального переполнения нет; ссылки навигации работают.
- axe WCAG A/AA/2.1 AA: автоматическая проверка desktop/mobile; контраст исправлен по найденным нарушениям. Это автоматическая проверка, не полная сертификация доступности.
- Рабочие три источника прочитаны новым загрузчиком: все записи корректно разобраны, пропущенных строк нет. Данные и доступы к таблице не изменялись.
- Визуальная проверка через локальный браузер: desktop и mobile, морской фон, состояние демонстрации, рабочий источник.

## Решения и ограничения

Использованы независимые ES-модули вместо новых микросервисов: проект остаётся статическим и работает на существующем GitHub Pages. Framework/runtime dependencies не добавлены; npm-пакеты нужны лишь для разработки.

Демо помечено отдельно и не выдаётся за рабочие показатели. Соотношение отзывов и QR-сканов не связывает конкретные сессии, поэтому может превышать 100%; оно не является точной воронкой пользователей. Переходы на платформы не означают опубликованные там отзывы. Небольшое число оценок у лидера отображается явно; статистическая значимость не заявляется.

Данные Google Sheets доступны по прежней публичной схеме. Приложение не добавляет авторизацию и не меняет ACL таблицы. Внешние шрифты загружаются с Google Fonts с системными fallback-шрифтами. Ручная проверка Safari/Firefox и длительные аппаратные замеры FPS не выполнялись.
