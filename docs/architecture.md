# Архитектура

AdminFeedback — статический браузерный дашборд. Google Sheets остаётся источником данных; отдельный backend не требуется для текущей публичной схемы доступа.

```text
Google Sheets: Reviews / Scans / PlatformClicks
                   ↓ три параллельных fetch, timeout + AbortController
               src/data.js
          parse → validate → normalize
                   ↓ records + per-source status
 app.js filters → src/analytics.js → src/view.js → DOM / SVG
                                       ↑
                                 src/motion.js
```

## Границы модулей

- `src/config.js`: публичные идентификаторы таблицы/листов, часовой пояс, timeout и размер страницы.
- `src/data.js`: GViz-протокол, строгие civil dates, оценки, нормализация имён, параллельное обновление и сохранение устаревшего снимка при сбое. Никаких DOM-зависимостей.
- `src/analytics.js`: чистые расчёты, единый scope периода/сотрудника, распределение оценок, тренд и сортировка. Нет fetch или глобального состояния.
- `src/view.js`: безопасное построение DOM через `textContent`, SVG-график, пагинация. Значения из Google Sheets не становятся HTML.
- `src/motion.js`: мягкое появление реальных значений без интерполяции чисел, IntersectionObserver, пользовательская пауза и системное reduced motion. Декоративное движение на CSS transforms приостанавливается в скрытой вкладке.
- `src/theme.js`: системная тема до явного выбора пользователя, переключатель, сохранение предпочтения и синхронизация между вкладками. Короткий bootstrap в head применяет тему до загрузки CSS; контроллер приложения не записывает системную тему как выбор пользователя.
- `src/demo.js`: отдельный opt-in демонстрационный набор, загружается динамически только по `?demo=1`.
- `app.js`: небольшой контроллер фильтров, обновления и событий.

## Расчёты и производительность

Каждый источник фильтруется по периоду и сотруднику один раз на пересчёт. Агрегация сотрудников использует `Map` и проход по каждому набору, без вложенного поиска сканов для каждого сотрудника. Для 14 дней выполняется постоянное число проходов по отфильтрованным отзывам. Лента создаёт 30 DOM-карточек за раз, а не весь массив. Запрос поиска обновляет только ленту; основной рейтинг не меняется из-за фильтра негативных отзывов.

Недельные окна привязаны к календарю Актау и выбранному периоду. Исторический месяц заканчивается последним днём месяца; отсутствие свежих отзывов не превращает старую дату в «сегодня». Дни без отзывов — пропуски графика, не нулевые оценки. Временная метка без смещения считается локальным временем источника; ISO со смещением приводится к `Asia/Aqtau`.

## Почему без микросервисов

Исходный монолитный JS разделён по ответственности на ES-модули. HTTP-сервисы для нескольких клиентских расчётов добавили бы хостинг, сетевые отказы и эксплуатацию без практической пользы. Если понадобятся закрытые данные, роли, аудит доступа или серверное кеширование, нужен авторизованный backend/BFF перед Google Sheets; это отдельное изменение модели доступа.

## Состояния данных

`loading` → `ready` либо `error`. При повторной ошибке уже загруженного источника — `stale`; сохраняются его записи и время прежней успешной загрузки. Баннер явно называет недоступные источники. Пустая успешная таблица даёт нулевое количество, недоступная — `—`. Частичная ошибка сканов не скрывает отзывы. Повторное обновление нельзя запустить параллельно с текущим.

Снимки отзывов живут только в памяти вкладки. `localStorage` хранит только тему и переключатель анимации. При недоступном storage переключение продолжает работать в текущей вкладке. Таблицы публично читаются браузером: GitHub Pages, адрес «admin» и клиентская конфигурация не являются авторизацией. Доступ к самой таблице не изменён.

## Визуальная система 2.1

Обе темы заданы семантическими CSS-токенами: поверхности, текст, границы, фон/текст статусов, графики и морской фон. Тема не реализована инверсией изображения или фильтром над страницей. Изменение темы не пересчитывает метрики, не сбрасывает фильтры и не повторяет запросы.

`.caspian-background` — отдельный фиксированный декоративный слой за приложением: SVG с тремя волнами и пенными контурами. `aria-hidden` и `pointer-events:none` не позволяют ему мешать чтению и управлению. Существующая пауза и системный reduced motion отключают и фон, и остальные анимации.

Верхняя панель закреплена и показывает текущий контекст. Переход к негативным отзывам меняет только фильтр ленты, сохраняет период/сотрудника, очищает поисковый запрос и переводит фокус к заголовку раздела. Данные и формулы сохранены. Подробный разбор решений: [design-review.md](design-review.md).

## Ориентиры

Единый scope фильтров и визуальная иерархия опираются на [Linear Dashboards](https://linear.app/docs/dashboards). Морская палитра, авторские SVG-волны и контуры отсылают к Каспию и Актау. Формат источника описан в [Google Visualization Data Source Protocol](https://developers.google.com/chart/interactive/docs/dev/implementing_data_source).
